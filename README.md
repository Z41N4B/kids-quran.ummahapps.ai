# Learning Surahs ⭐

A colorful app to help children memorize short surahs of the Quran.

**Surahs:** Al-Fatiha, Ayatul Kursi (in 10 sections), Al-Insan, Al-Asr, Al-Kawthar, Al-Kafirun, Al-Ikhlas, Al-Falaq and An-Nas.

## Features
- Tap any ayah to hear it, or **Play all** to go through the whole surah
- **Repeat** each ayah 1, 3, 5 or 10 times
- **Hide words** to test yourself (tap a line to peek)
- ⭐ Mark ayahs as learned and track progress on the home page
- 7 background colors, including a pink-to-blue gradient

## Audio
Recitation by Saad al-Ghamdi, from [everyayah.com](https://everyayah.com/). See `audio/README.txt` for the file layout.

## Running locally
```
node serve.js
```
